# Team Directory App

A simple React team directory for browsing members, searching, saving favorites, and viewing details.

## Features

- Home, Users, User Details, About, and 404 pages
- React Router navigation with active link styling
- Search users by name or role (case-insensitive)
- Favorites with live count in the Navbar
- Dark mode / light mode toggle
- Simulated loading state with Loader component
- Error messages for "No users found" and "User not found"
- Document title updates per page

## Technologies Used

- React + Vite
- Tailwind CSS
- react-router-dom

## Description

This project uses local user data from `src/data/users.js` (no API or backend).
It demonstrates reusable components, props, `useState`, `useEffect`, and React Router.
Run with `npm install` then `npm run dev`, and build with `npm run build`.
